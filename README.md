# Sistema de Gestão de Pedidos de Produção

Projeto acadêmico desenvolvido em equipe no **SENAI**, como parte das
atividades de integração das unidades curriculares de Linguagem de
Marcação, Programação Back-End, Banco de Dados e Projetos, sob
orientação do professor Rogério.

## Sobre o projeto

O Sistema de Gestão de Pedidos de Produção tem como proposta organizar e
acompanhar os pedidos de uma empresa, centralizando informações e
facilitando o controle das etapas do processo produtivo.

A solução busca oferecer uma estrutura para registrar pedidos,
acompanhar seu andamento e manter os dados organizados. O projeto também
contempla a criação de uma interface para interação com os usuários e a
integração com uma estrutura de banco de dados.

## Objetivo

Desenvolver, em equipe, um sistema que integre os conhecimentos
trabalhados nas unidades curriculares, contemplando:

- Uma interface organizada e funcional;
- Operações CRUD (Create, Read, Update e Delete);
- Um banco de dados para armazenamento das informações;
- Uma estrutura de aplicação bem organizada;
- Planejamento, documentação e desenvolvimento colaborativo.

## Funcionalidades previstas

De acordo com o escopo apresentado para o projeto, o sistema deverá
contemplar:

- **Página institucional:** apresentação da empresa e de suas
  informações;
- **Login:** acesso dos usuários ao sistema;
- **Cadastro de pedidos:** registro das solicitações de produção;
- **Acompanhamento de pedidos:** consulta do andamento dos pedidos;
- **Navegação:** menus, botões e telas para facilitar o uso;
- **Banco de dados:** armazenamento e gerenciamento das informações;
- **Operações CRUD:** criação, consulta, atualização e exclusão de
  registros.

As funcionalidades podem ser detalhadas e ajustadas durante as etapas de
desenvolvimento.
